# قالب فروشگاه ولتا (لوازم جانبی موبایل)

قالب ایستا (HTML/CSS/JS)، فارسی، RTL کامل، با تم روشن/تیره و ریسپانسیو. بدون build و بدون وابستگی؛ فقط `index.html` را باز کنید یا هر پوشه‌ی استاتیک سرو کنید.

```
template/
  index.html        ساختار صفحه‌ی Home (header، hero، دسته‌ها، محصولات، بنرها، برندها، نظرات، footer)
  css/tokens.css    رنگ‌ها، radius، سایه، فونت (تنها جای تغییر ظاهر برند)
  css/styles.css    استایل کامپوننت‌ها (ProductCard، دکمه‌ها، گرید، ...)
  js/data.js        محصولات و دسته‌ها (اینجا ویرایش کنید)
  js/app.js         رندر کارت‌ها، wishlist، افزودن به سبد، toast، شمارنده، تم
  DESIGN.md         قوانین کامل طراحی (منبع حقیقت)
```

## شخصی‌سازی سریع
1. **نام برند:** در `index.html` عبارت «ولتا» را عوض کنید (logo، footer، title).
2. **رنگ‌ها:** در `css/tokens.css` متغیرهای `--action` (لینک/فوکس)، `--charge` (رنگ برند روی سطح تیره) و `--sale` (تخفیف) را تغییر دهید. تم تیره زیر `prefers-color-scheme` و `[data-theme="dark"]` است.
3. **محصولات:** `js/data.js` را ویرایش کنید. قیمت‌ها به تومان و عدد صحیح‌اند.
4. **عکس واقعی:** در `card()` داخل `js/app.js` به‌جای `<svg class="art"><use .../></svg>` از `<img class="art" src="..." alt="...">` استفاده کنید (تصویر PNG/WebP شفاف روی پس‌زمینه‌ی `--studio`، نسبت ۱:۱). کلاس `.art` سایه‌ی محصول را خودش اعمال می‌کند.
5. **فونت:** Vazirmatn از Google Fonts لود می‌شود. برای سایت بدون اینترنت، فایل فونت را self-host کنید و `@font-face` اضافه کنید.

## استفاده در پروژه‌ی دیگر
- **سایت ایستا / PHP / Laravel Blade / Django:** پوشه را کپی کنید؛ `css`، `js` و بخش‌های `index.html` را به قالب‌های خودتان ببرید.
- **Next.js / React:** `tokens.css` را در `globals.css` وارد کنید، `styles.css` را کپی کنید، تابع `card()` را به یک کامپوننت `ProductCard` تبدیل کنید و `data.js` را با API خودتان عوض کنید.
- **Tailwind:** مقادیر `tokens.css` را در `theme.extend` بگذارید.

## قواعد مهم (خلاصه‌ی DESIGN.md)
- فقط logical properties (`inline-start/end`)، نه `left/right`.
- فقط یک CTA اصلی مشکی (pill) در هر viewport؛ قرمز فقط برای قیمت تخفیف؛ رنگ `charge` فقط روی سطح تیره.
- ارقام فارسی و `tabular-nums` برای قیمت؛ نام برند/مدل لاتین داخل `<bdi>`.
- قبل از تغییر ظاهر، `DESIGN.md` را به‌روز کنید.
