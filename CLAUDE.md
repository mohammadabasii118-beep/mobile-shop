# CaseLine — Project Instructions

## Design System (mandatory)
`DESIGN.md` in the repo root is the single source of truth for the UI design system (Framer-based, with a CaseLine Persian/RTL adaptation layer at the bottom).

**Before making ANY change to UI** (anything under `src/components`, `src/pages`, `src/features`, `src/layouts`, `src/index.css`, `tailwind.config.js`, or any visual/CSS/layout edit), read `DESIGN.md` first and follow it. If a requested change conflicts with `DESIGN.md`, say so and ask before deviating. Do not restyle existing UI to match `DESIGN.md` unless the user has approved that change.

## Stack & commands
React 18 + TypeScript + Vite + Tailwind + Framer Motion + React Three Fiber. Persian, RTL.
`npm install` · `npm run dev` · `npm run typecheck` · `npm run build`
