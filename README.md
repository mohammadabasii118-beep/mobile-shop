# موبایل‌شاپ

فروشگاه استاتیک لوازم جانبی موبایل (منوی همبرگری، سبد خرید، پرداخت کارت‌به‌کارت).

- اجرا: `python3 -m http.server` و باز کردن `http://localhost:8000`
- شماره کارت و اطلاعات فروشگاه: `config.js`
- محصولات و دسته‌بندی‌ها: `products.js`

نکته: چون بک‌اند ندارد، سفارش‌ها در مرورگر مشتری ذخیره می‌شوند؛ برای دریافت سفارش، آی‌دی تلگرام را در `config.js` بگذارید تا رسید سفارش به تلگرام شما ارسال شود. برای تأیید خودکار پرداخت، بک‌اند لازم است.
