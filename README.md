# Aurora — فروشگاه سینمایی لوازم جانبی آیفون

یک وب‌سایت لوکس، مدرن و اسکرول‌محور برای فروش لوازم جانبی موبایل.
ایده اصلی: یک آیفون واقع‌گرایانه در مرکز صفحه می‌ماند و با اسکرول کاربر،
مرحله‌به‌مرحله لوازم جانبی (قاب، گلس، شارژر، پاوربانک، ایرپاد) به آن اضافه
می‌شوند تا یک مجموعه کامل شکل بگیرد — با حس تبلیغات سینمایی محصولات اپل.

A cinematic, scroll-driven storefront for iPhone accessories. An iPhone stays
pinned at the centre of the screen while accessories fly in stage-by-stage as
the user scrolls, building into a complete collection — then the page opens into
a fully interactive shop.

---

## ✨ امکانات

- **داستان اسکرول سینمایی** — آیفون پین‌شده در مرکز، ورود مرحله‌ای ۷ محصول با
  حرکت سه‌بعدی، چرخش و تغییر مقیاس، هماهنگ با میزان اسکرول (GSAP ScrollTrigger).
- **اسکرول نرم** با Lenis و همگام‌سازی کامل با انیمیشن‌ها.
- **فروشگاه کامل و واقعی**: محصولات پرفروش، جدیدترین‌ها، نمایش دسته‌بندی‌ها،
  کاتالوگ با فیلتر دسته‌بندی، کارت محصول، صفحه جزئیات (مودال)، انتخاب رنگ و تعداد.
- **سبد خرید عملکردی** با ذخیره‌سازی محلی (localStorage)، کشوی سبد، محاسبه جمع و
  هزینه ارسال، و مرحله «تکمیل خرید» آماده اتصال به درگاه پرداخت.
- **فرم ارتباط** با اعتبارسنجی، راه‌های ارتباطی و لینک شبکه‌های اجتماعی و فوتر حرفه‌ای.
- **کاملاً ریسپانسیو** (موبایل، تبلت، دسکتاپ) و راست‌به‌چپ (RTL) با فونت وزیرمتن.
- **دسترس‌پذیری**: احترام کامل به `prefers-reduced-motion` — در این حالت به‌جای
  انیمیشن سنگین، مجموعه کامل به‌صورت ترکیب‌بندی ثابت نمایش داده می‌شود.
- **بهینه**: کامپوننت‌های مجزا، بارگذاری تدریجی با `whileInView`، بدون اسکرول
  افقی ناخواسته، و رندرهای وکتور سبک.

## 🧱 پشته فناوری

| لایه | فناوری |
|------|--------|
| UI | React 18 + TypeScript |
| استایل | Tailwind CSS 3 |
| انیمیشن اسکرول | GSAP + ScrollTrigger |
| اسکرول نرم | Lenis |
| تعاملات UI | Framer Motion |
| باندلر | Vite 5 |

> طبق خواسته پروژه، فقط کتابخانه‌های لازم نصب شده‌اند. Three.js اضافه نشد چون
> افکت عمق و پرسپکتیو سه‌بعدی به‌صورت سبک‌تر با ترنسفورم‌های GSAP و رندرهای وکتور
> لایه‌ای پیاده‌سازی شد (سازگارتر با موبایل و گوشی‌های ضعیف).

## 🚀 اجرا

```bash
npm install      # نصب وابستگی‌ها
```

## 🖼️ تصاویر محصولات — مهم

محصولات با **رندرهای وکتور SVG با جزئیات بالا** ساخته شده‌اند (گرادیان فلزی
تیتانیوم، بازتاب نور روی شیشه، شفافیت گلس، نورپردازی و سایهٔ استودیویی). این
رندرها **شفاف، سبک و مستقلاً قابل‌انیمیشن** هستند — دقیقاً همان چیزی که برای
کُرئوگرافی اسکرول لازم است — و برخلاف اشکال سادهٔ CSS، لایه‌لایه و واقع‌گرایانه
طراحی شده‌اند.

### جایگزینی با رندرهای واقعی (عکس/AI/Blender)

اگر رندرهای واقعی با پس‌زمینهٔ شفاف دارید، فایل‌ها را با همین نام‌ها در پوشهٔ
`public/products/` قرار دهید (فرمت `PNG` یا `WebP`، پس‌زمینهٔ شفاف، زاویه و
نورپردازی هماهنگ):

```
public/products/
├─ iphone-front.webp      # آیفون، نمای جلو
├─ iphone-back.webp       # آیفون، نمای پشت
├─ case.webp              # قاب گوشی
├─ glass.webp             # گلس محافظ
├─ adapter.webp           # آداپتور شارژ
├─ cable.webp             # کابل شارژ
├─ powerbank.webp         # پاوربانک
└─ airpods.webp           # کیس/ایرپاد
```

سپس در `src/components/art/ProductArt.tsx` کافی است هر `case` را به یک `<img>`
با مسیر فایل مربوطه تغییر دهید (ساختار کامپوننت‌ها برای این جایگزینی آماده است).
تا زمان افزودن تصاویر واقعی، رندرهای وکتور فعلی به‌صورت پیش‌فرض استفاده می‌شوند و
کیفیت بصری کامل را حفظ می‌کنند.
