# ولتا (Volta) — فروشگاه لوازم جانبی موبایل (Demo)

فروشگاه فارسی/RTL با تجربهٔ سه‌بعدی. **فاز فعلی: Demo برای تأیید Design System** (دادهٔ mock، بدون Backend/پرداخت).

- `DESIGN.md` — منبع حقیقت UI (اول این را بخوان)
- `CLAUDE.md` — workflow پروژه

## اجرا
```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```
