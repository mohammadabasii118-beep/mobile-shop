# موبایل‌شاپ — فروشگاه لوازم جانبی موبایل

فروشگاه فارسی (راست‌چین، موبایل‌محور) بدون هیچ وابستگی؛ فقط Node.js ≥ 18.

```bash
npm start            # http://localhost:3000
# پنل مدیریت: http://localhost:3000/admin   (رمز پیش‌فرض: admin123 — حتماً عوض کنید)
```

متغیرهای محیطی: `PORT`، `ADMIN_PASSWORD` (رمز اولیه)، `SESSION_SECRET` (ثابت نگه دارید تا با ری‌استارت، ورود مدیر نپرد).

## امکانات سایت
- اسلایدر بنر خودکار با دکمه قبلی/بعدی، نقطه‌ها و کشیدن انگشتی
- ۴ باکس انیمیشنی زیر بنر (قاب و کاور، کاور ایرپاد، کابل و شارژر، لوازم جانبی)
- ریل افقی دسته‌ها (کاور آیفون، کاور اندروید، بند و آویز، ...)
- بخش‌های پرفروش‌ترین و تخفیف‌خورده (خودکار)
- منوی چندسطحی: قاب و کاور (سامسونگ/شیائومی/آیفون)، کاور ایرپاد (مدل‌های ایرپاد)، کابل و شارژر، لوازم برقی، لوازم جانبی (گلس، بند و آویز، ...)
- تنوع محصول (رنگ، مدل گوشی، طول، ...) با انتخاب در صفحه محصول و سبد خرید
- پرداخت آنلاین (زرین‌پال) و کارت‌به‌کارت با ثبت رسید
- پیگیری سفارش با کد سفارش + موبایل

## پنل مدیریت (`/admin`)
داشبورد فروش، مدیریت سفارش‌ها (تایید رسید، وضعیت، کد رهگیری)، محصولات (تصویر، تنوع، موجودی، تخفیف)، دسته‌ها و منو، بنرها، باکس‌ها و ریل صفحه اصلی، تنظیمات پرداخت/ارسال و تغییر رمز.

## درگاه پرداخت
در پنل ← تنظیمات ← «مرچنت‌کد زرین‌پال» را وارد کنید. تا وقتی خالی باشد از درگاه آزمایشی داخلی استفاده می‌شود (بدون دریافت پول واقعی). برای پول واقعی حالت Sandbox را خاموش کنید. سایت باید روی دامنه‌ی HTTPS در دسترس باشد تا بازگشت از درگاه کار کند.

داده‌ها در `data/db.json` و تصاویر در `uploads/` ذخیره می‌شوند (از آن‌ها بکاپ بگیرید).
