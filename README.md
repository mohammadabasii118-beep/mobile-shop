# استودیوی مافیای قاب 🎬

اپلیکیشن ادیت قسمت‌های سریال اینستاگرامی **«مافیای قاب»** برای **ویندوز** و **اندروید**.
این اپ دقیقاً همان کاری را می‌کند که ربات پایتونی `tool/editor.py` می‌کرد:

شروع تند ← «قسمت قبل...» ← تیتر قسمت ← صحنه‌ها با زیرنویس فارسی (فحش‌ها با ستاره)
← برچسب مکان‌ها ← کارت پایانی با سؤال کامنت. صدا هم برای اینستاگرام نرمال می‌شود.

همه‌چیز روی گوشی یا کامپیوتر خودت کار می‌کند؛ هیچ اینترنت و توکنی لازم نیست.

---

## ۱) اول از همه: فایل‌های ساخته‌شده را از کجا بگیرم؟

کد این اپ روی گیت‌هاب است و هر بار که تغییری push می‌شود، گیت‌هاب **خودکار** دو فایل می‌سازد:
- `MafiaGhab-Android-APK` → برای گوشی اندروید
- `MafiaGhab-Windows` → یک فایل zip برای ویندوز

### گرفتن فایل‌ها (قدم‌به‌قدم):
۱. به صفحه‌ی ریپوی خودت برو:
   `https://github.com/mohammadabasii118-beep/mobile-shop`
۲. بالای صفحه روی تبِ **Actions** کلیک کن.
۳. از لیست، **آخرین اجرا** (بالاترین مورد، با تیک سبز ✅) را باز کن.
   اگر دایره‌ی زرد 🟡 بود یعنی هنوز در حال ساخت است؛ چند دقیقه صبر کن (معمولاً ۵ تا ۱۵ دقیقه).
۴. پایین همان صفحه، بخش **Artifacts** را می‌بینی. روی هرکدام کلیک کنی دانلود می‌شود:
   - **MafiaGhab-Android-APK** → فایل APK گوشی
   - **MafiaGhab-Windows** → فایل zip ویندوز

> نکته: گیت‌هاب فایل‌ها را داخل یک zip به تو می‌دهد؛ بعد از دانلود، از zip درش بیاور.

---

## ۲) نصب روی گوشی (اندروید)

۱. فایل `app-release.apk` را روی گوشی باز کن.
۲. اگر گفت «نصب از منابع ناشناس»، اجازه بده (Settings → اجازه نصب).
۳. اپ نصب می‌شود؛ اسمش «استودیوی مافیای قاب» است.

---

## ۳) اجرا روی ویندوز

۱. فایل `MafiaGhab-Windows.zip` را از zip درش بیاور، یک‌جای ساده بگذار (مثلاً `C:\MafiaGhab`).
۲. داخل پوشه، روی `mafia_ghab_editor.exe` دوبار کلیک کن.
۳. همین! `ffmpeg.exe` از قبل داخل همین پوشه هست؛ نیازی به نصب چیزی نیست.

> پوشه را کامل نگه دار؛ فایل exe به کنارِ خودش (ffmpeg.exe و پوشه‌ی data) نیاز دارد.

---

## ۴) کار با اپ

۱. **صفحه‌ی خانه:** فصل‌ها و قسمت‌ها را می‌بینی (قسمت‌های ۴ تا ۱۶ داخل اپ هست).
   با دکمه‌ی **«وارد کردن فصل»** می‌توانی فایل `season2.json` فصل بعد را اضافه کنی.
۲. **یک قسمت را باز کن.** لیست صحنه‌ها را می‌بینی (شماره، عنوان، گوینده، متن زیرنویس).
۳. **ویدیو بگذار:** برای هر صحنه دکمه‌ی «انتخاب ویدیو»، یا بالا سمت چپ دکمه‌ی
   **انتخاب گروهی** (چندتا ویدیو را یک‌جا انتخاب کن؛ اگر اسم فایل‌ها شماره دارد
   مثل `01.mp4` خودش می‌چیند، وگرنه به ترتیب).
   - هر کلیپ: بندانگشتی، **پیش‌نمایش** (▶)، **برش** (✂) برای کوتاه‌کردن ابتدا/انتها.
۴. دو راه ساخت:
   - **«ساخت قسمت»**: مستقیم می‌سازد.
   - **«زیرنویس و پیش‌نمایش»**: اول زیرنویس‌ها را خودکار زمان‌بندی می‌کند، بعد می‌توانی
     متن و زمان هر خط را ویرایش کنی و هر کلیپ را با زیرنویسِ رویش پیش‌نمایش ببینی،
     بعد **«ساخت نهایی»**.
۵. **خروجی:** وقتی ساخته شد، یک پنجره باز می‌شود:
   - اندروید: **ذخیره در گالری** (Movies/MafiaGhab) یا **اشتراک** (برای اینستاگرام).
   - ویندوز: **ذخیره در پوشه...** (هر جا خواستی).
   - گزینه‌ی **۷۲۰p سریع** (بالای صفحه‌ی قسمت) برای خروجی سبک‌ترِ گوشی.
۶. **کپشن:** بالای صفحه‌ی قسمت، آیکن #. کپشن پست + کامنت نظرسنجی + هشتگ‌ها آماده است،
   با دکمه‌ی کپی.

> **«قسمت قبل...»** خودکار از کلیپ‌های قسمت قبلی ساخته می‌شود؛ برای همین قسمت‌ها را
> به ترتیب بساز و پروژه‌ها پاک نشوند. اگر قسمت قبلی را نساخته باشی، این بخش رد می‌شود.

> کار هر قسمت **خودکار ذخیره** می‌شود؛ می‌توانی اپ را ببندی و بعداً ادامه بدهی.

---

## ۵) اگر خواستی یک ریپوی گیت‌هاب تازه بسازی

ریپوی تو از قبل هست و لازم نیست کاری کنی. ولی اگر روزی خواستی از صفر بسازی:
۱. به `https://github.com/new` برو.
۲. یک اسم بگذار (مثلاً `mafia-ghab`)، گزینه‌ی **Private** را بزن، **Create repository**.
۳. فایل‌های این پروژه را در آن ریپو بگذار (push کن).
۴. تبِ **Actions** خودش شروع به ساختن APK و zip ویندوز می‌کند.

## برای برنامه‌نویس‌ها (اجرای محلی)

نیاز: Flutter (کانال stable).

```bash
flutter pub get
flutter test                 # تست‌ها (پورت VAD/زیرنویس و ساخت ویدیوی نمونه)
flutter run -d windows       # اجرا روی ویندوز (ffmpeg باید روی PATH باشد یا کنار exe)
flutter build apk --release  # ساخت APK اندروید
flutter build windows --release
```

### معماری
- `lib/models/` — مدل داده (فصل/قسمت/صحنه، پروژه).
- `lib/services/subtitle/` — پورت دقیق VAD (`vad.dart`) و زمان‌بندی زیرنویس
  (`subtitle_timing.dart`) از `editor.py`.
- `lib/services/overlay_renderer.dart` — رندر اورلی‌ها با canvas فلاتر (مطابق CSS).
- `lib/services/ffmpeg/` — واسط `FFmpegService`؛ ویندوز با Process (ffmpeg باندل‌شده)،
  اندروید با `ffmpeg_kit_flutter_new`.
- `lib/services/build_service.dart` — پورت `make_spec` + `build` با دستورهای عیناً `editor.py`.
- `lib/screens/` — رابط کاربری فارسی (خانه، قسمت، ویرایش زیرنویس، کپشن، پیش‌نمایش).

### چرا خروجی مثل editor.py است؟
همه‌ی دستورهای ffmpeg (کراپ، اسکیل، آن‌شارپ، eq، fps، overlay، xfade، loudnorm، CRF،
کارت پایانی) عیناً از `editor.py` منتقل شده‌اند. فقط مرحله‌ی ساخت اورلی که قبلاً با
Playwright/Chromium بود، با canvas خود فلاتر (همان فونت‌ها و همان موقعیت/رنگ CSS) جایگزین شده.

فایل مرجع اصلی: `reference/MafiaGhab/tool/editor.py`
