# 🤖 PCL Transfer Bot

ربات تلگرامی ثبت آگهی بازیکن آزاد و جذب بازیکن برای تیم‌های پروکلاب (aiogram 3 + SQLite + ZarinPal).

## راه‌اندازی

```bash
pip install -r requirements.txt
cp .env.example .env   # توکن، آیدی مدیران و مرچنت‌کد زرین‌پال را پر کنید
python run.py
```

- ربات برای انتشار آگهی باید در گروه/کانال نقل‌وانتقالات ادمین باشد؛ سپس در `/admin ← 📡 گروه انتشار` آیدی آن را ثبت کنید.
- بازگشت از درگاه زرین‌پال روی `ZARINPAL_CALLBACK_URL` (پیش‌فرض مسیر `/zarinpal/callback` روی `WEB_PORT`) انجام می‌شود؛ این آدرس باید از اینترنت به ربات برسد (reverse proxy).
- لینک صفحه پرداخت: `ZARINPAL_STARTPAY_URL` + Authority (پیش‌فرض `https://sub.pclproclubss.ir/pg/StartPay/`).

## ساختار
| فایل | وظیفه |
|---|---|
| `pclbot/handlers/user.py` | منو، مشخصات، نشان‌ها، دعوت، کارت هدیه، پشتیبانی |
| `pclbot/handlers/ads.py` | ثبت آگهی (پیش‌نمایش/ویرایش)، آگهی‌های من، تمدید، ارتقا به ویژه |
| `pclbot/handlers/wallet.py` | کیف پول، شارژ، تاریخچه تراکنش |
| `pclbot/handlers/admin.py` | پنل مدیریت (`/admin`) |
| `pclbot/services.py` | تأیید/رد/انتشار، نشان‌ها، پاداش دعوت، انقضای خودکار |
| `pclbot/payments.py` | زرین‌پال + وب‌سرور کال‌بک |

## قوانین مهم
- هزینه آگهی هنگام ثبت از کیف پول کسر می‌شود و در صورت رد/حذف قبل از تأیید برگردانده می‌شود.
- نشان‌ها و پاداش دعوت فقط با **اولین تأیید** یک آگهی **غیرتکراری** حساب می‌شوند؛ ویرایش و تمدید چیزی اضافه نمی‌کند.
- همه تعرفه‌ها، مدت اعتبار، پاداش دعوت، متن خوشامد و نشان‌ها از پنل مدیریت قابل تغییرند.

تست آفلاین منطق: `python -m tests.smoke`

## ایموجی پرمیوم
ایموجی‌های همه پیام‌ها، آگهی‌ها و آیکون دکمه‌ها از `/admin ← ✨ ایموجی‌ها` به ایموجی پرمیوم تلگرام تبدیل می‌شوند:
روی هر ایموجی بزنید و یک ایموجی پرمیوم (یا استیکر ایموجی) بفرستید؛ شناسه خودکار ذخیره می‌شود و بدون ری‌استارت اعمال می‌شود.
فهرست ایموجی‌ها و جایگزین‌های معمولی در `pclbot/emojis.py` است. شرط تلگرام: صاحب ربات باید اشتراک پرمیوم داشته باشد
و پیام در پیوی/گروه/سوپرگروه باشد. اگر تلگرام درخواستی را رد کند، همان پیام با ایموجی معمولی ارسال می‌شود.

تست آفلاین: `python -m tests.emoji_test`

## انتقال کامل ربات به سرور دیگر (بکاپ + نصب)
روی سرور **قدیمی**:
```
bash /opt/pcl-transfer/deploy/backup.sh          # → ~/pcl-backup-DATE.tar.gz (کد + .env + دیتابیس + لوگو/پس‌زمینه‌ها)
scp ~/pcl-backup-*.tar.gz root@IP_SERVER_JADID:/root/
sudo systemctl stop pclbot                       # توکن را نمی‌شود هم‌زمان از دو سرور پولینگ کرد
```
روی سرور **جدید** (Ubuntu/Debian، root):
```
tar xzf /root/pcl-backup-*.tar.gz -C /tmp ./deploy/install.sh && bash /tmp/deploy/install.sh /root/pcl-backup-*.tar.gz
```
بعد: DNS دامنه‌ی کال‌بک زرین‌پال را روی IP جدید ببر و nginx/certbot را مثل قبل با `deploy/nginx.conf` بساز. فایل بکاپ شامل `.env` است؛ بعد از انتقال حذفش کن.
