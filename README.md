# Caseline؛ فروشگاه لوازم جانبی موبایل

فروشگاه اینترنتی فارسی (RTL) با **پنل مدیریت کامل**، **محصول متغیر مثل ووکامرس** (رنگ، برند گوشی، مدل گوشی) و **هیروی کشویی** که بنرهایش را از پنل مدیریت می‌سازید.

**Next.js 16 · React 19 · TypeScript · SQLite (better-sqlite3) · بدون سرویس خارجی.** پایگاه داده و تصاویر در یک پوشه (`data/`) ذخیره می‌شوند؛ پشتیبان‌گیری یعنی کپی همین پوشه.

---

## ۱. اجرای سریع

نیازمند Node.js 20 یا بالاتر.

```bash
npm install
npm run seed        # ساخت پایگاه داده + داده‌ی نمونه (محصول، بنر، سفارش …)
npm run dev         # http://localhost:3000
```

پنل مدیریت: **http://localhost:3000/admin** ← نام کاربری `admin`، رمز `admin123` (بعد از ورود، از «تنظیمات ← حساب من» عوضش کنید؛ تا عوض نکنید داشبورد هشدار می‌دهد).

| دستور | کار |
|---|---|
| `npm run seed` | داده‌ی نمونه‌ی کامل (فقط اگر پایگاه داده خالی باشد) |
| `npm run seed -- --empty` | فقط مدیر + ویژگی‌های پایه (رنگ، برند و مدل گوشی …)؛ برای شروع فروشگاه واقعی |
| `npm run seed:reset` | **همه‌ی داده‌ها را پاک** می‌کند و دوباره می‌سازد |
| `npm run build && npm start` | اجرای نهایی (production) |
| `npm run smoke` | تست دودی روی سرور در حال اجرا |
| `npm run typecheck` | بررسی TypeScript |

رمز مدیر اولیه را می‌توانید قبل از seed با `ADMIN_LOGIN` و `ADMIN_PASSWORD` تعیین کنید (`.env.example`).

## ۲. امکانات

**سایت فروشگاه**
- صفحه‌ی اصلی: **اسلایدر بنر کشویی** (خودکار، swipe در موبایل، فلش و نقطه، توقف، RTL)، دسته‌ها، محصولات ویژه، پیشنهاد ویژه با شمارنده، جدیدترین‌ها، بنرهای تبلیغاتی، برندها، نظرات مشتریان.
- فروشگاه با فیلتر برند، دسته، قیمت، موجودی، تخفیف و **«سازگار با گوشی من»** (برند ← مدل؛ محصولات مخصوص آن مدل بالاتر می‌آیند و محصولات عمومی مثل شارژر هم نمایش داده می‌شوند). مدل انتخابی یادآوری می‌شود و در صفحه‌ی محصول از قبل انتخاب می‌شود.
- صفحه‌ی محصول متغیر: انتخاب **برند ← مدل ← رنگ** (فقط ترکیب‌های موجود فعال‌اند)، قیمت و موجودی و تصویر هر گونه، تأیید سازگاری با گوشی مشتری.
- جستجوی زنده (نرمال‌سازی ی/ک و ارقام فارسی)، علاقه‌مندی‌ها، سبد خرید (قیمت‌ها همیشه از سرور محاسبه می‌شود)، کد تخفیف، ارسال رایگان از یک مبلغ، تسویه حساب مهمان یا عضو، حساب کاربری و سفارش‌ها، نظر و امتیاز، تم روشن/تیره، سئو (sitemap، robots، JSON-LD).

**پنل مدیریت** (`/admin`)
داشبورد با راهنمای راه‌اندازی · محصولات (ساده و متغیر) · **ویژگی‌ها** · دسته‌بندی‌ها · برندها · موجودی · سفارش‌ها · پرداخت‌ها · تخفیف گروهی · کد تخفیف · نظرات · کاربران · **بنرها و اسلایدر با پیش‌نمایش زنده** · گزارش‌ها · تنظیمات. جستجوی سراسری با `Ctrl+K` یا `/`، خروجی CSV برای سفارش‌ها.

همه‌ی صفحه‌ها در عرض‌های ۳۲۰ تا ۱۹۲۰ پیکسل بدون اسکرول افقی تست شده‌اند.

## ۳. راهنمای پنل مدیریت

سایدبار به گروه‌های **فروش، کاتالوگ، مشتریان، محتوا، سیستم** تقسیم شده؛ عدد کنار «سفارش‌ها»، «موجودی» و «نظرات» یعنی مورد منتظر اقدام. در داشبورد، تا وقتی راه‌اندازی تمام نشده، یک چک‌لیست ۶ مرحله‌ای می‌بینید.

### ساخت محصول متغیر (مثلاً قاب)
۱. **ویژگی‌ها** را یک‌بار تعریف کنید (در seed آماده‌اند): «برند گوشی»، «مدل گوشی» (زیرمجموعه‌ی برند)، «رنگ»، «طول کابل»، «ظرفیت». مقدارهای جدید را از `ویژگی‌ها ← انتخاب ویژگی ← افزودن مقدار` اضافه کنید (برای رنگ، کد رنگ هم می‌گیرد؛ چندتایی هم می‌شود افزود).
۲. `محصولات ← محصول جدید`، نام را بنویسید و «**محصول متغیر**» را بزنید.
۳. «ویژگی‌های پیشنهادی» را بزنید و مقدارها را تیک بزنید: برند Apple و Samsung، مدل‌هایشان، رنگ‌ها. مدل‌ها فقط برای برندهای تیک‌خورده نمایش داده می‌شوند.
۴. قیمت پیش‌فرض را بنویسید و «**ساخت متغیرها**» را بزنید. همه‌ی ترکیب‌های معتبر ساخته می‌شود (Samsung × iPhone ساخته نمی‌شود).
۵. قیمت، قیمت تخفیفی و موجودی هر گونه را وارد کنید (ابزار گروهی: قیمت، موجودی، درصد تخفیف برای همه یا فقط فیلترشده‌ها). برای هر گونه می‌توانید تصویر اختصاصی بگذارید.
۶. «ساخت محصول» را بزنید. بعداً با تغییر مقدارها و زدن دوباره‌ی «ساخت متغیرها»، گونه‌های جدید اضافه می‌شوند و قیمت‌های قبلی حفظ می‌شوند.

### بنرها
`بنرها و اسلایدر ← بنر جدید`. دو نوع: **اسلایدر اصلی** (کشویی) و **بنر تبلیغاتی میانی**. دو چیدمان: «متن + محصول» یا «تمام‌تصویر» (عکس آماده‌ی تبلیغاتی دسکتاپ + موبایل). در متن عنوان، Enter خط جدید می‌سازد و `*کلمه*` رنگی می‌شود. ترتیب با فلش، زمان‌بندی با تاریخ شروع و پایان.

### کارهای روزمره
- **سفارش جدید:** `سفارش‌ها` ← وضعیت، کد رهگیری، یادداشت. لغو یا مرجوع کردن موجودی را به انبار برمی‌گرداند.
- **پرداخت در محل:** در `پرداخت‌ها` پس از دریافت وجه «ثبت موفق» بزنید.
- **تخفیف:** گروهی روی دسته یا برند از `تخفیف‌ها`؛ تکی در صفحه‌ی ویرایش محصول.
- **موجودی:** `موجودی` ← ویرایش سریع هر ردیف.

## ۴. ساختار پروژه

```
src/app/(shop)/            صفحه‌های فروشگاه (/، /shop، /product، /cart، /checkout …)
src/app/admin/(panel)/     صفحه‌های پنل مدیریت
src/app/api/               suggest، upload، admin/search
src/lib/db.ts              اتصال SQLite و schema (همه‌ی جدول‌ها اینجاست)
src/lib/catalog.ts         خواندن محصول، دسته، بنر، تنظیمات
src/lib/orders.ts          قیمت‌گذاری سبد، کوپن، ثبت سفارش، موجودی
src/lib/variations.ts      منطق خالص ساخت و انتخاب متغیرها
src/lib/actions/           Server Actionها (shop، admin-*)
src/lib/payments.ts        درگاه پرداخت (راهنمای اتصال درگاه واقعی)
src/components/shop|admin  کامپوننت‌ها
scripts/seed.ts            داده‌ی اولیه
DESIGN.md · CLAUDE.md      سیستم طراحی و راهنمای کار با Claude
```

### مدل داده (SQLite)
`products` (simple/variable) · `variations` (attrs به‌صورت JSON مثل `{"phone-brand":"apple","phone-model":"iphone-15","color":"black"}`) · `attributes` + `attribute_terms` (با `parent` برای برند ← مدل) · `product_attributes` · `categories` · `brands` · `banners` · `coupons` · `orders` + `order_items` + `payments` · `inventory_log` · `reviews` · `users` · `settings`.

## ۵. استقرار

**سرور مجازی (VPS):**
```bash
npm ci && npm run build
npm run seed -- --empty          # یک‌بار
ADMIN_PASSWORD='رمز-قوی' …       # قبل از seed
PORT=3000 npm start              # پشت nginx با HTTPS؛ برای اجرای دائمی از pm2 یا systemd استفاده کنید
```
**Docker:**
```bash
echo "ADMIN_PASSWORD=رمز-قوی" > .env
docker compose up -d --build     # داده‌ها در volume به نام shop-data
```
- متغیرها: `NEXT_PUBLIC_SITE_URL` (برای sitemap)، `DATA_DIR` (مسیر پوشه‌ی داده)، `SESSION_SECRET` (اختیاری)، `INSECURE_COOKIES=1` (فقط اگر پشت HTTPS نیستید).
- **پشتیبان:** پوشه‌ی `data/` را (شامل `shop.db` و `uploads/`) کپی کنید؛ برای نسخه‌ی روشن (hot) از `sqlite3 data/shop.db ".backup backup.db"` استفاده کنید.
- فونت وزیرمتن داخل پروژه است و به اینترنت خارجی نیاز ندارد.

## ۶. درگاه پرداخت

«پرداخت آنلاین» فعلاً **آزمایشی** است و پولی کسر نمی‌کند، پس در حالت production خاموش است (فقط «پرداخت در محل» نمایش داده می‌شود) مگر `PAYMENT_MODE=test` تنظیم کنید. برای اتصال به زرین‌پال یا درگاه دیگر، راهنمای ۳ مرحله‌ای بالای `src/lib/payments.ts` را دنبال کنید؛ ساختار سفارش و پرداخت (جدول `payments`) آماده است.

## ۷. نکات امنیتی

رمزها با scrypt ذخیره می‌شوند؛ نشست با کوکی امضاشده (HttpOnly، SameSite=Lax)؛ تلاش ورود محدود است؛ همه‌ی Actionهای مدیریتی دسترسی مدیر را بررسی می‌کنند؛ آپلود فقط تصویر واقعی (بررسی محتوا، نه فقط پسوند) تا ۶ مگابایت؛ کوئری‌ها پارامتری‌اند؛ قیمت سفارش همیشه از دیتابیس محاسبه می‌شود نه از مرورگر. قبل از انتشار: رمز مدیر را عوض کنید، HTTPS بگذارید و از `data/` پشتیبان بگیرید.

## ۸. کارهای احتمالی بعدی

پیامک وضعیت سفارش، اتصال درگاه واقعی، آدرس‌های ذخیره‌شده‌ی مشتری، بازیابی رمز با پیامک، چند انبار یا چند روش ارسال، تاریخ‌ساز شمسی در فرم‌ها (فعلاً ورودی تاریخ مرورگر است).
