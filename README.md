# میراث — Telegram Mini App

بازی کارتی نوبتی ۳ به ۳ (سولو در برابر ربات + مولتی‌پلیر آنلاین)، فارسی و راست‌چین.

## اجرا روی کامپیوتر (کپی‌پیست)

نیاز: Node.js نسخه‌ی ۲۲ یا بالاتر.

```bash
npm install
npm test                 # اجرای تست‌ها
npm run build            # ساخت کلاینت
npm start                # اجرای سرور روی http://localhost:3000
```

بعد `http://localhost:3000` را در مرورگر باز کن. بیرون از تلگرام، یک بازیکن آزمایشی ساخته می‌شود.
برای تست مولتی‌پلیر دو تب باز کن: `http://localhost:3000/?u=1` و `http://localhost:3000/?u=2`
(هر دو روی «مولتی‌پلیر» بزنند). در جعبه‌ها دکمه‌ی «⏩ دمو» تایمر را رد می‌کند (فقط در حالت آزمایشی).

حالت توسعه (تغییرات کلاینت زنده): در دو ترمینال جدا `npm run dev:server` و `npm run dev:client` (آدرس: http://localhost:5173).


## نصب روی سرور (یک خط، به‌صورت root)

```bash
curl -fsSL https://raw.githubusercontent.com/mohammadabasii118-beep/mobile-shop/claude/card-battle-game/install.sh | bash
```
نسخه‌ی واقعی با ربات (توکن BotFather و شناسه‌ی عددی تلگرام خودت برای دسترسی به پنل مدیریت؛ شناسه را از @userinfobot بگیر):
```bash
curl -fsSL https://raw.githubusercontent.com/mohammadabasii118-beep/mobile-shop/claude/card-battle-game/install.sh | BOT_TOKEN="توکن" ADMIN_IDS="123456789" bash
```
اجرای دوباره‌ی همین دستور = به‌روزرسانی؛ داده‌ها حفظ می‌شوند. سرویس: `systemctl status miras`، لاگ: `journalctl -u miras -f`.

## پنل مدیریت
در بازی: پروفایل ← «پنل مدیریت» (فقط برای ادمین‌ها؛ در نصب تست برای همه). امکانات: ویرایش کارت‌ها، **آپلود/تغییر عکس هر کارت**، کارت جدید/حذف، پیش‌نمایش قدرت‌گیری ۶ لول، تنظیم جعبه/اقتصاد/ارتقا، جستجوی بازیکن، هدیه‌دادن و مسدودکردن، ویرایش کامل JSON. تغییرها بلافاصله و بدون ری‌استارت اعمال و در `shared/config/game.json` ذخیره می‌شوند. عکس‌ها در `data/uploads/cards/` ذخیره می‌شوند.

## ساخت ربات تلگرام و باز کردن بازی داخل تلگرام

۱. در تلگرام با **@BotFather** گفتگو کن، `/newbot` را بزن، اسم و یوزرنیم (آخرش `bot`) بده. **توکن** را نگه دار (مثل `123456:ABC...`). آن را جایی منتشر نکن.
۲. برای تست، به یک آدرس **HTTPS** عمومی نیاز داری. ساده‌ترین راه (بدون ثبت‌نام):
   ```bash
   # ترمینال ۱ — سرور با توکن واقعی
   npm run build
   BOT_TOKEN="توکن_تو" npm start
   # ترمینال ۲ — تونل (cloudflared را از سایت cloudflare نصب کن)
   cloudflared tunnel --url http://localhost:3000
   ```
   آدرسی مثل `https://xxxx.trycloudflare.com` می‌دهد.
۳. در BotFather: `/newapp` (یا `/mybots` ← ربات ← Bot Settings ← Menu Button) و آدرس HTTPS را به‌عنوان Web App بده.
۴. ربات را در تلگرام باز کن و دکمه‌ی منو را بزن. بازی با اسم و آواتار تلگرام باز می‌شود.

> وقتی `BOT_TOKEN` تنظیم باشد، ورود آزمایشی هم همچنان فعال است مگر `NODE_ENV=production` باشد.
> در حالت production سرور بدون `BOT_TOKEN` بالا نمی‌آید و ورود آزمایشی غیرفعال است. ورود فقط با initData تأییدشده‌ی تلگرام ممکن است.

## انتشار روی سرور

```bash
docker build -t card-battle .
docker run -d -p 3000:3000 -e BOT_TOKEN="توکن" -v cardbattle-data:/data card-battle
```
پشت یک پروکسی HTTPS (مثل Caddy یا nginx) بگذار که WebSocket را هم رد کند (مسیر `/ws`).
داده‌ها در SQLite (`/data/game.db`) ذخیره می‌شوند؛ از آن فایل پشتیبان بگیر.

## ویرایش کارت‌ها و بالانس (بدون دست‌زدن به کد)

همه‌چیز در **`shared/config/game.json`**: آمار کارت‌ها، توانایی‌ها، هزینه‌ی ارتقا، جدول XP، جعبه (زمان، سکه، شانس کارت)، مرحله‌های سولو و مهلت ۱۰ ثانیه‌ای. بعد از تغییر سرور را دوباره اجرا کن.

- **اضافه‌کردن کارت:** یک آبجکت جدید در `cards`.
- **توانایی‌های موجود:** `double_strike` (چند حمله در نوبت)، `lifesteal` (دزدیدن جان)، `armor_up` (شیلد هر نوبت)، `revive` (یک بار زنده‌شدن).
- **کارت‌های فعلی:** گیو، بیژن، آرش کمانگیر (ساده؛ کارت‌های شروع هر بازیکن)، گردآفرید و کاوه آهنگر (معمولی)، سهراب (کمیاب). آمار و عددهای توانایی هر لول در `levels` هر کارت است. با بالا بردن `contentVersion` در `game.json`، کارت‌ها/ترکیب اولیه/سولوی ذخیره‌شده از پنل با نسخه‌ی کد جایگزین می‌شوند و کارت‌های حذف‌شده از حساب بازیکن‌ها پاک می‌شود.
- **توانایی جدید:** در `shared/src/abilities.ts` یک ورودی با هوک‌های `onTurnStart`، `onAttack`، `onDeath`، `attacksPerTurn` اضافه کن و `id` آن را روی کارت بنویس. تست‌ها در `shared/tests/engine.test.ts` نمونه‌اند.

## آرت

فعلاً هر کارت یک placeholder رنگی دارد. ساده‌ترین راه: از پنل مدیریت عکس هر کارت را آپلود کن. راه دیگر: فایل `<id کارت>.png` را در `client/public/assets/cards/` بگذار (عکس آپلودشده اولویت دارد).

## ساختار پروژه

| پوشه | کار |
|---|---|
| `shared/` | موتور مبارزه (مستقل از UI/شبکه + تست)، توانایی‌ها، تنظیمات، پروتکل |
| `server/` | سرور (HTTP + WebSocket)، دیتابیس، تأیید تلگرام، جعبه/ارتقا، مچ‌میکینگ، اجرای مبارزه |
| `client/` | React + Vite، رابط فارسی |

## قوانین امنیتی که رعایت شده
- منطق مبارزه، سکه، XP، جعبه و تایمرها فقط روی سرور؛ کلاینت فقط «کدام کارت به کدام کارت حمله کند» را می‌فرستد و سرور اعتبارسنجی می‌کند.
- تایمر ۱۵ ثانیه‌ای و تایمر جعبه روی ساعت سرور.
- initData تلگرام روی سرور با HMAC تأیید می‌شود (با محدودیت ۲۴ ساعته).
- قطع اتصال وسط مبارزه = باخت. سقف مخفی ۱۰۰ دور؛ تساوی با جان+شیلد.

## سولو: گودال‌ها
۳ گودال × ۲۰ لول (کلاً ۶۰ لول، پشت‌سرهم باز می‌شوند). حریف هر لول (۳ تا ۵ کارت با لولشان و هوش ربات) از پنل مدیریت ← «سولو (گودال‌ها)» ویرایش می‌شود. مقدارهای اولیه خودکار با سختی افزایشی چیده شده‌اند و برای بالانس نهایی‌اند.

## ذخیره‌ی تنظیمات پنل مدیریت
هر چه از پنل ذخیره کنی (کارت‌ها، اقتصاد، گودال‌ها، بنر) در `data/game.json` ذخیره می‌شود و با به‌روزرسانی کد پاک نمی‌شود. بخش‌های جدیدی که در نسخه‌های بعدی اضافه شوند خودکار از تنظیمات پیش‌فرض کد گرفته می‌شوند.

## جعبه‌ها و آمار کارت‌ها
- سه نوع جعبه (برنزی، نقره‌ای، طلایی) هر کدام با زمان باز شدن، سکه، XP، تعداد کارت و شانس کارتِ جدا. از پنل مدیریت ← «جعبه و اقتصاد» ویرایش می‌شود. جعبه‌ی جایزه‌ی برد: سولو بر اساس گودال، مولتی‌پلیر با شانس (همان‌جا قابل تنظیم).
- آمار هر لول هر کارت یک جدول مستقل است (بدون فرمول رشد): پنل مدیریت ← «کارت‌ها» ← «آمار هر لول».

## نوع کارت و هزینه‌ی ارتقا
سه نوع کارت: **ساده** (برنزی)، **معمولی** (نقره‌ای)، **کمیاب** (طلایی). هزینه‌ی ارتقای هر نوع جدا تنظیم می‌شود: پنل مدیریت ← «جعبه و اقتصاد» ← «هزینه‌ی ارتقا» ← انتخاب نوع کارت. (در فایل تنظیمات، نوع‌ها با `common`، `rare` و `epic` ذخیره می‌شوند.)

## شانس جعبه با هر برد
پنل مدیریت ← «جعبه و اقتصاد» ← «شانس دریافت جعبه با هر برد»: برای سولو و آنلاین جدا، درصد دریافت جعبه‌ی برنزی، نقره‌ای و طلایی. مجموع حداکثر ۱۰۰٪؛ باقی‌مانده یعنی با آن برد جعبه‌ای نمی‌آید.

## عضویت اجباری کانال
قبل از بازی، یک‌بار از بازیکن می‌خواهد عضو کانال شود (پیش‌فرض `@MirasGame`). ربات باید **ادمین کانال** باشد تا بتواند عضویت را بسنجد. با «عضو شدم» از تلگرام پرسیده می‌شود و نتیجه در دیتابیس ذخیره می‌شود؛ بعد از آن دیگر نشان داده نمی‌شود. ادمین‌های بازی از شرط معافند. در حالت تست (بدون توکن) اجرا نمی‌شود. آیدی کانال و روشن/خاموش بودنش: پنل مدیریت ← «ظاهر و بنر».

## پس‌زمینه‌ی بازی و پیام‌های ربات
- پس‌زمینه: پنل مدیریت ← «ظاهر و بنر» ← «پس‌زمینه‌ی بازی» (آپلود عکس عمودی).
- پیام اول `/start` (متن معرفی) از همان تب قابل تغییر است؛ پیام دوم «هر وقت آماده بودی، بزن بریم👇» با دکمه‌ی ورود به بازی.

## آدرس HTTPS ثابت (به‌جای تونل رایگان)
تونل رایگان cloudflared روی بعضی اینترنت‌ها بسته یا ناپایدار است (خطای `ERR_CONNECTION_REFUSED` در تلگرام) و با ری‌استارت آدرسش عوض می‌شود. برای آدرس ثابت و مستقیم روی همین سرور (پورت ۸۰ و ۴۴۳ باید آزاد باشند):
```bash
curl -fsSL https://raw.githubusercontent.com/mohammadabasii118-beep/mobile-shop/claude/card-battle-game/scripts/https.sh | bash
```
بدون دامنه از آدرس رایگان `miras.<IP>.sslip.io` استفاده می‌کند. با دامنه‌ی خودت: `DOMAIN=miras.example.com` (قبلش A رکورد را به IP سرور بزن).

## بکاپ روزانه در ربات
در حالت واقعی (BOT_TOKEN و ADMIN_IDS تنظیم شده) هر روز بعد از ساعت ۳ بامداد UTC (حدود ۶:۳۰ ایران) یک فایل `miras-backup-تاریخ.tar.gz` فقط برای ادمین‌ها در پیام خصوصی ربات فرستاده می‌شود: همه‌ی کد (با node_modules و build) + دیتابیس (کاربرها) + عکس‌ها + تنظیمات پنل (بدون فایل توکن `/etc/miras.env`؛ اگر از سقف تلگرام بزرگ‌تر شود چیزی حذف نمی‌شود و فایل به تکه‌های ۴۵ مگابایتی تقسیم می‌شود؛ برای وصل‌کردن: `cat miras-backup-*.tar.gz.part* > miras-backup.tar.gz`). هر ادمین باید یک‌بار به ربات /start بزند. بکاپ فوری: ارسال `/backup` به ربات. ساعت: `BACKUP_HOUR_UTC` در /etc/miras.env؛ خاموش: `BACKUP=off`.

## کاپ، XP و جایزه‌ها
- **کاپ** فقط از نبرد آنلاین: هر برد +۱۰، هر باخت −۶ (هیچ‌وقت زیر صفر نمی‌رود). جدول «نفرات برتر» با دکمه‌ی جام در صفحه‌ی اصلی.
- **آنلاین:** هر برد ۵ XP و ۷۰ سکه (+ جعبه طبق شانس). **تک‌نفره:** فقط جعبه (طبق تنظیمات پنل).
- **XP** فقط از دو راه: برد آنلاین و ارتقای کارت (مقدارش در جدول هزینه‌ی ارتقا، ستون «XP دریافتی»). جعبه‌ها XP نمی‌دهند.
- همه‌ی این عددها در پنل مدیریت ← «جعبه و اقتصاد» (بخش «جایزه‌ی نبرد آنلاین») قابل تغییر است.

## فروشگاه
- تب «فروشگاه» (سمت چپ منوی پایین): ۶ پیشنهاد کارت روزانه (هر اسلات فقط یک قیمت دارد: با الماس یا با سکه، هر بازیکن هر پیشنهاد را روزی یک‌بار)، باکس سکه (هر بسته یا با الماس، فوری، یا با تومان، کارت‌به‌کارت) و خرید الماس (با تومان).
- همه‌چیز از پنل مدیریت ← «فروشگاه» تنظیم می‌شود: اسلات‌های کارت، بسته‌ها، قیمت‌ها، آدرس درگاه پرداخت، و لیست سفارش‌ها.
- **خرید الماس، دو روش:** (۱) کارت‌به‌کارت: مشخصات کارت (در پنل می‌گذاری) به بازیکن نشان داده می‌شود، او واریز می‌کند و کد پیگیری می‌نویسد، تو در پنل می‌بینی (شناسه‌ی عددی، نام، تاریخ، مقدار، کد پیگیری) و «تحویل» را می‌زنی. (۲) استار تلگرام: پرداخت داخل خود تلگرام و تحویل **خودکار** (ربات باید روشن باشد). هر سفارش فقط یک‌بار تحویل می‌شود.

## جعبه‌ها: تک‌نفره (دانجن) و آنلاین
- محتوای هر نوع جعبه (سکه، تعداد و شانس کارت) برای جعبه‌ای که از **تک‌نفره** می‌آید و جعبه‌ی **آنلاین** جدا تنظیم می‌شود (پنل ← جعبه و اقتصاد). جعبه‌ی دانجن در بازی کهنه و با ریشه و برگ نشان داده می‌شود.
- **باز کردن فوری با الماس:** برای هر ۱۰ دقیقه‌ی باقی‌مانده ۲ الماس (رو به بالا گرد می‌شود: ۱۲ دقیقه = ۴، ۲۵ دقیقه = ۶، یک ساعت = ۱۲). هر دو عدد از پنل قابل تغییر است.

- **سفارش فقط بعد از پرداخت دیده می‌شود:** باز کردن پنجره‌ی خرید (کارت‌به‌کارت یا فاکتور استار) هیچ چیزی در پنل و «سفارش‌های اخیر» نمی‌گذارد. کارت‌به‌کارت با «پرداخت کردم» + کد پیگیری ثبت می‌شود؛ استار بعد از پرداخت واقعی (به‌صورت تحویل‌شده) دیده می‌شود.

## نبرد ۵ در ۵ (کشیدن و رها کردن)
- ترکیب ۳ تا ۵ کارت (`deckSize` در کانفیگ). نوبت‌ها یکی‌درمیان است ولی کارتِ حمله‌کننده را خود بازیکن انتخاب می‌کند: کارت خودش را بکشد روی کارت حریف.
- قانون خاموشی: کارتی که حمله کرد، اگر صاحبش ۴ یا ۵ کارت زنده دارد ۲ نوبتِ بعدی خودش خاموش است؛ با ۳ کارت ۱ نوبت؛ با ۲ کارت یا کمتر خاموشی ندارد.
- قدرت ویژه: هر کارت (`chargeAttacks`، در پنل مدیریت ← کارت‌ها) بعد از چند حمله نوارش پر می‌شود و حمله‌ی بعدی همه‌ی عددهای توانایی‌هایش ۲ برابر می‌شود.

## کارت‌ها (۱۶ کارت)
جدول کامل آمار و توانایی‌ها در `shared/config/game.json` است (ساده: گیو، بیژن، آرش، گودرز، توس، هکتور، رهام؛ معمولی: گردآفرید، کاوه، سیاوش، آشیل، پری، کیرکه؛ کمیاب: سهراب، فرامرز، آرتمیسیا). عددهای «ضربه‌ی ویژه» هر کارت در `special` همان لول ذخیره شده (اگر نباشد ۲ برابر عدد عادی است). توانایی‌ها در `shared/src/abilities.ts`: خشم، سپر هم‌تیمی، نفوذ، جان‌ربایی، پخش ضربه، ضربه‌ی کاری، سپر درخشان (پشتیبان؛ روی هم‌تیمی)، سم، آتش‌گذر، ضربه‌ی دوباره، شکستن شیلد.

## حالت بروزرسانی، کد جایزه، پیشنهاد هفتگی
- پنل مدیریت ← «ظاهر و بنر» ← «عکس بروزرسانی»: عکس را آپلود و «فعال» کن؛ همه به‌جز ادمین‌ها فقط عکس را می‌بینند و نمی‌توانند بازی کنند. غیرفعال کنی، خودکار وارد بازی می‌شوند.
- پنل مدیریت ← «کد جایزه»: کد با جایزه (سکه، الماس، XP، کارت، جعبه) بساز یا حذف کن. بازیکن از منو ← «کد جایزه» می‌زند؛ هر نفر هر کد را یک‌بار.
- پیشنهاد کارت فروشگاه هفتگی است (هر شنبه ۰۰:۰۰ تهران). بازیکن تازه ۵ کارت ساده می‌گیرد (`startingDeck`).

## تسک‌های هفتگی
هر شنبه ۰۰:۰۰ (تهران) ۱۰ تسک تازه از «پایگاه نمونه‌ها» (`weekly.pool` در `game.json`، ۴۳ نمونه) ساخته می‌شود؛ جایزه‌های نگرفته می‌سوزند و شمارنده‌ها صفر می‌شوند. نوع‌ها: برد تک‌نفره، برد آنلاین، باز کردن جعبه، ارتقای کارت، خرج سکه، برد پشت‌سرهم. جوایز هر هفته در مجموع ۲۰۰۰ سکه + ۲۰ الماس + ۲۰۰ XP + ۲ جعبه (برنزی/نقره‌ای) به نسبت سختی. پنل مدیریت ← «تسک هفتگی»: نوع، هدف و جایزه‌ی هر اسلات را عوض کن؛ برای کسی که جایزه‌ی آن تسک را گرفته چیزی عوض نمی‌شود. بازی دوستانه در تسک‌ها و آمار حساب نمی‌شود.
