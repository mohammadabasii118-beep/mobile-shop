# قابلیت‌های جدید (پنل ادمین ← «⚙️ پنل ویژگی‌های جدید»)

همه‌ی جدول‌ها با پیشوند `fx_` در همان فایل دیتابیس قبلی ساخته می‌شوند (بدون دست‌زدن به داده‌های ترنسفر/ONC).

| بخش | کاربر | ادمین |
|---|---|---|
| 🌍 اشتراک بین‌المللی (USDT) | منو ← اشتراک بین‌المللی ← پرو (چپ) / استاندارد (راست) ← ۶ ماهه / ۱ ساله ← ارسال رسید | رسید فوری می‌آید: ✅ تایید / ❌ رد (+ دلیل). تنظیم قیمت‌ها، ولت و شبکه |
| 🚫 بلک‌لیست | منو ← بلک‌لیست (فقط مشاهده) | افزودن با آیدی بازیکن ← علت؛ حذف؛ جلوگیری از تکرار |
| ⚽ مسابقه فوتبالی | اعلام آمادگی ← سر ساعت سؤال‌ها (۴ دکمه، ۱۰ ثانیه) ← امتیاز/رتبه؛ 🏆 تالار قهرمانان (۱ تا ۳ هر دوره) | بانک سؤال (سطح آسان/متوسط/سخت؛ سؤال نمونه یا ورود از فایل JSON/CSV)، ساخت مسابقه (عنوان، جایزه، زمان، تعداد هر سطح)، شروع فوری، اطلاع‌رسانی |
| 📝 درفت | وقتی ادمین باز کند در منو دیده می‌شود: آیدی بازیکن، پست اصلی، پست دوم (اختیاری) | باز/بستن، لیست به‌تفکیک پست، خروجی CSV، پاک کردن |
| 🎥 استریمرها | استریمر: عکس + تایتل ← پیش‌نمایش ← انتشار در «پلاس» | افزودن/حذف استریمر با آیدی عددی/فوروارد/@username؛ تعیین کانال «پلاس» |
| ⚡ Here We Go | — | روشن/خاموش، کانال انتشار، پیش‌نمایش آخرین ترنسفر. هر ۲ دقیقه `GET /transfers`؛ بار اول فقط ترنسفرهای موجود را به‌خاطر می‌سپارد |
| 🎨 گرافیک‌های اپ | — | برنامه روز، جدول، نتایج، براکت از API اپ ← پیش‌نمایش ← انتشار. قالب‌ها همان قالب‌های قابل‌ویرایش ONC هستند (نوع جدید: «ترنسفر نیوز») |

## نکات
- API اپ: `https://api.pclproclub.ir/api/v1` (فقط GET عمومی). محدودیت ۶۰ درخواست در دقیقه با فاصله‌ی حداقل ۱٫۲ ثانیه و کش ۶۰ ثانیه رعایت می‌شود. زمان‌ها UTC هستند و به Asia/Tehran تبدیل می‌شوند.
- مسابقه: همه‌ی سؤال‌ها هم‌زمان برای همه ارسال می‌شود؛ مهلت هر نفر از لحظه‌ی رسیدن سؤال به خودش حساب می‌شود. رتبه: بیشترین جواب درست، سپس کمترین زمان جواب‌های درست.
- قیمت‌های پیش‌فرض اشتراک (USDT): استاندارد ۳ / ۵ ، پرو ۴ / ۸ (۶ ماهه / ۱ ساله) — از پنل قابل تغییر است.
- تست: `PYTHONPATH=. python3 tests/fx_test.py`

## گرافیک‌های اپ (🎨) — ترتیب کار
۱) مسابقه را انتخاب کن (🏅 لیگ / 🏆 جام / 🌐 تورنمنت) ← ۲) تب: 📊 جدول · ✅ نتایج (آخرین نتایج یا یک راند) · 📅 برنامه روزانه (روزهای دارای بازی) · 🗓 برنامه راندی/مرحله‌ای (ساعت + تایتل) · 🏆 براکت · 📈 آمار بازیکنان (گلزن، پاس گل، دروازه‌بان، میانگین امتیاز) · ⭐ تیم منتخب (کل یا یک راند) ← ۳) پیش‌نمایش ← انتشار.
قالب‌ها در «🎨 قالب‌ها»ی پنل ONC قابل ویرایش‌اند (انواع جدید: «آمار بازیکنان (اپ)» و «تیم منتخب (اپ)»).
