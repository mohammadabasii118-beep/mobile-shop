# 🌍 مولتی‌لوکیشن (اتصال ربات به پنل VPN)

ربات از API پنل (`vpn-panel/panel/API.md`) استفاده می‌کند: ساخت کاربر، تمدید، گرفتن مصرف و لینک اشتراک.

## نصب
در `/opt/pcl-transfer/.env` این دو خط را بگذار و ربات را ری‌استارت کن:
```
VPN_PANEL_URL=https://panel.sibdata1.cfd
VPN_PANEL_API_KEY=<PANEL_API_KEY داخل /opt/vpn-panel/vpn-panel/.env روی سرور پنل>
```
کلید را فقط داخل `.env` سرور بگذار؛ هیچ‌جا در چت یا گیت نفرست.

## ادمین (⚙️ پنل ویژگی‌های جدید ← 🌍 VPN مولتی‌لوکیشن)
وضعیت اتصال و تعداد لوکیشن‌های آنلاین، فهرست پلن‌ها، ➕ پلن جدید (نام ← حجم ← روز ← قیمت)، روشن/خاموش، حذف. اطلاع خرید و تمدید به ادمین می‌آید.

## کاربر
دکمه‌ی «🌍 مولتی‌لوکیشن» در منوی اصلی (فقط وقتی پنل وصل است و حداقل یک پلن فعال هست):
پلن‌ها ← خرید از کیف پول ← لینک اشتراک؛ «📋 سرویس‌های من» (وضعیت، مصرف، روز مانده، لینک، 🔁 تمدید)؛ «📍 لوکیشن‌ها».

## ایمنی
- پول اول از کیف پول کم می‌شود؛ اگر پنل خطا بدهد یا قطع باشد، همان لحظه برمی‌گردد و چیزی ساخته نمی‌شود.
- هر کاربر فقط سرویس‌های خودش را می‌بیند و تمدید می‌کند. نام تکراری (۴۰۹) با پسوند تصادفی دوباره امتحان می‌شود.
- پلن حذف‌شده یا غیرفعال فروخته نمی‌شود؛ سرویس‌های قبلی کار می‌کنند ولی تمدید ندارند. پلن «نامحدود در زمان» تمدید ندارد.
- تست: `PYTHONPATH=. python3 tests/vpn_test.py`
