# مدل‌های سه‌بعدی واقعی محصولات (GLB / GLTF)

فایل مدل واقعی محصول را اینجا بگذارید، سپس در `src/lib/products.ts` روی همان محصول
فیلد `model` را ست کنید:

```ts
model: "/models/nova-smartwatch-pro.glb",
```

- اگر `model` ست شود، صفحهٔ جزئیات به‌جای شکل primitive، **مدل واقعی قابل‌چرخش**
  را نمایش می‌دهد (و برچسب هم به «نمای سه‌بعدی واقعی» تغییر می‌کند).
- فرمت‌های پشتیبانی‌شده: `.glb` (ترجیحی) و `.gltf`.
- برای وب بهینه کنید (Draco/Meshopt، حجم کم) تا FPS افت نکند.
