پرش سریع به قابلیت‌ها

برای دیدن هر بخش روی آن بزنید یا از منوی خود ربات شروع کنید.

pclbot/emojis.py (پیشنهادی) 
CUSTOM = {   # نام: (custom_emoji_id, ایموجی جایگزین)
    "PLAYER": ("PLACEHOLDER_1", "🎮"),
    "TEAM":   ("PLACEHOLDER_2", "🛡"),
    "TROPHY": ("PLACEHOLDER_3", "🏆"),
}

def ce(name):
    cid, fb = CUSTOM[name]
    if cid.startswith("PLACEHOLDER"):
        return fb        # بدون ID واقعی = ایموجی معمولی
    return f'<tg-emoji emoji-id="{cid}">{fb}</tg-emoji>'
  • تا وقتی ID واقعی نگذاشته‌اید، همه‌چیز مثل الان می‌ماند.
  • دکمه‌های شیشه‌ای ایموجی معمولی می‌مانند.
  • کاربر بدون پرمیوم هم ایموجی را می‌بیند.

درگاه پرداخت و گروه انتشار هم شبیه‌سازی شده‌اند. برای دیدن آگهی در گروه، یک آگهی را از نقش «مدیر» تأیید کنید.
